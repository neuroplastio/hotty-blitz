# Kitesurf leg 4: covered changes

- Parley 0.12 patch 0005 (breaks around out-of-flow and atomic boxes) is not ported: on 0.13 forced newlines are appended as text and contribute line metrics before the explicit break (upstream Parley a7c1c56); the existing hotty Parley patch `Give inline boxes the wrap mode of their span` covers the wrap-mode and intrinsic-width portions. A host regression checks the two out-of-flow/forced-break sequences and consecutive inline blocks under `white-space:nowrap` on this base.
- Blitz DOM 0003 (implicit max-size for replaced elements) is skipped: upstream Blitz 42821263fc370e4363b75c2d40e52bfe5d7eed98 removes the available-space clamp on both axes. This is broader than kitesurf's retained natural-image shrink leniency; restoring that leniency would undo part of the upstream fix. Host tests check an authored canvas overflowing its container and a percentage-width SVG under a zero-height ancestor.
- Leg 5 design input: an absolutely positioned descendant whose containing block is outside an `opacity:.5` ancestor currently paints outside that ancestor's effect layer, fully opaque. `effect_overflow.rs::opacity_layer_includes_positioned_descendant_with_outer_containing_block` pins the expected pixel and is ignored until the out-of-flow paint-tree work.
- Blitz DOM 0023's detailed grid capture and resolved grid-style consumer are already in upstream Blitz 813c496bf and 33af534a5 respectively. The table painter uses the existing retained `computed_grid_info`; no second grid storage patch is needed.
- Table follow-ups, already present at f7af686: captions are omitted, and collapsed-border widths and colors are resolved globally instead of per edge. The Chromium oracle fixture with a caption, mixed borders and spanning cells is retained under `~/.cache/hotty-kitesurf/leg4-oracle/`.
- Rotated repeating gradient backgrounds: `vault/bench/r33/dots.html` shows a triangular or band-shaped portion of the dots on rotated cards in both f7af686 and leg 4. The pre-existing gradient tiler applies each tile translation after the base transform; leg 4's viewport culling also treats the transformed axes independently. Correct placement and conservative culling for rotation/skew need to be addressed together, including the tile-count cap and scrolled/fixed backgrounds; this is a follow-up rather than a one-line change.
