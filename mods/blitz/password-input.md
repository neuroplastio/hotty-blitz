---
title: "Mask and edit password inputs"
patch: 0021-Mask-and-edit-password-inputs.patch
upstream-fit: yes
---

A password input keeps its value beside a bullet-masked editor and synchronises edits, submission and type changes. The value is not copied or cut, and a double click selects the whole mask, whose bullets are not words. Hotty forms need password fields; these browser behaviours and their tests belong upstream.
